Restored & Connected

  • Global Beta Feedback FAB: Restored the floating feedback button across all application screens with screen capture preview and automated device telemetry.

v1.2.0 September 2026

Added & Modernized

  • Renamed to "My Services": Bottom navigation tab 2 and spend headers now emphasize "My Services" with the streaming channels stack icon (Icons.Default.Subscriptions).
  • Movie Details Markdown Transformation: Converted raw monospace YAML frontmatter and markdown in the movie sheet into interactive theme pills, cast badges, and structured insight cards.
  • Direct Explore Bridge: Added 1-tap "Discuss with Olivia & Gemini in Explore" action directly inside the movie sheet.
  • Cinephile Taste Matrix: Visual multi-segment genre distribution bar in Explore based on real watched vault data.
  • 1-Tap Recommendations: Added instant + Watchlist addition to all Gemini Pro recommendations in Explore.

v1.1.0 September 2026

Added & Fixed

  • Default to "My Services": The Watchlist tab now launches with the "My Services" filter chip enabled by default, prioritizing movies currently streaming on your active subscriptions.
  • Live TMDB Availability & Metadata Sync: Fixed TMDB API integration to pull live posters, backdrop art, ratings, overview, and streaming provider mappings.
  • Coroutine Instant Sync: Immediate UI-reactive metadata sync on app launch and manual pull-to-refresh without waiting for background periodic workers.
  • Expanded Provider Ecosystem: Added automated matching for Criterion Channel, Peacock, Paramount+, Mubi, Shudder, Starz, BritBox, Tubi, Freevee, and Pluto TV.
  • WorkManager Collision Fix: Resolved name collision between periodic worker and one-time immediate worker.
