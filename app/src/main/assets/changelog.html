Streamwise Release Changelog

v1.1.0 September 2026

Added & Fixed

  • Default to "My Services": The Watchlist tab now launches with the "My Services" filter chip enabled by default, prioritizing movies currently streaming on your active subscriptions.
  • Live TMDB Availability & Metadata Sync: Fixed TMDB API integration to pull live posters, backdrop art, ratings, overview, and streaming provider mappings.
  • Coroutine Instant Sync: Immediate UI-reactive metadata sync on app launch and manual pull-to-refresh without waiting for background periodic workers.
  • Expanded Provider Ecosystem: Added automated matching for Criterion Channel, Peacock, Paramount+, Mubi, Shudder, Starz, BritBox, Tubi, Freevee, and Pluto TV.
  • WorkManager Collision Fix: Resolved name collision between periodic worker and one-time immediate worker.

v1.0.0 August 2026

Initial Foundation

  • Material 3 cinematic dark mode with dynamic theme toggle.
  • Local Room database with 400+ seed entries.
  • Subscription ROI calculator and watch history timeline.
