Smart Vibe Coding & Pacing

Design first, execute incrementally. Protect your high-reasoning context window and keep token usage lightweight.

Strategic Pacing Mode

1. Blueprint Before Prompt

Never feed the LLM a 1,000-line code file blindly asking to "fix this". Instead, extract the exact data structure (e.g., your Room MediaDao.kt interfaces) and draft your logic as architectural pseudocode first.

SAVINGS: ~70% context load High Leverage

2. Pure State Scaffolding

Separate Jetpack Compose UI layout layers from active DB operations. Model states as pure immutability classes. Test state transitions in isolation before integrating DB triggers inside your WorkManager.

SAVINGS: Fewer recomposes Clean Code

3. Model Tier Mapping

Use lightweight, cost-effective models (like Gemini 3.0 Flash) for routine formatting and TMDB API mappings. Reserve heavy models (Gemini 3.0 Pro) exclusively for advanced semantic synthesis and database triggers.

SAVINGS: Preserves premium limits Smart Sourcing
